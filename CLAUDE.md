## Для Claude Code

- Все правила проекта — в `AGENTS.md` выше; этот файл добавляет только то, что касается Claude.
- Работай в своей ветке (в desktop-приложении — в отдельном worktree на задачу), в `main` — только через PR.
- Превью: конфигурация `emli` в `.claude/launch.json` (`npm run dev`, порт 5173), вход — `?dev=1`/`?dev=2`.
  Если панель браузера скрыта, приложение в ней не грузится дальше заставки (rAF на паузе) — тогда проверяй через API/тесты и честно пиши, что глазами не видел.
- Узнал важное о проекте или договорились о правиле — допиши в `AGENTS.md` в том же PR, а не только в свою память: у второго разработчика другой Claude, и твоя память ему не видна.
- Личные настройки — в `.claude/settings.local.json` и `CLAUDE.local.md` (в git не попадают).
